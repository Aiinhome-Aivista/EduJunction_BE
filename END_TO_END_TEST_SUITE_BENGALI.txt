====================================================================================================
                       EduJunction (এডুজংশন) - সম্পূর্ণ এন্ড-টু-এন্ড টেস্ট কভারেজ ডকুমেন্ট
                     ICSE & CBSE Board Model Test Papers & Adaptive Exam Engine
====================================================================================================

প্রকল্পের বিবরণ:
EduJunction হল ICSE ও CBSE বোর্ডের (Class 9-12) শিক্ষার্থীদের জন্য একটি অ্যাডাপ্টিভ লার্নিং এবং অল-ইন-ওয়ান অনলাইন এক্সামিনেশন প্ল্যাটফর্ম। এতে পিতা-মাতার ড্যাশবোর্ড, সন্তান সংযোগ (Child linking), রেজারপে (Razorpay) পেমেন্ট গেটওয়ে, রিয়েল-টাইম অ্যাডাপ্টিভ টেস্ট ইঞ্জিন, ইন্টারেক্টিভ ক্যানভাস ডায়াগ্রাম ড্রয়িং ও ম্যাথ টুলকিট, এবং টেস্ট শেষে পিতা-মাতার ইমেলে স্বয়ংক্রিয়ভাবে বিস্তারিত PDF রিপোর্ট পাঠানোর সুবিধা রয়েছে।

                                  Phase 1: Admin & Config System Test
----------------------------------------------------------------------------------------------------
Test Case 1.1: এডমিন লগইন ও ড্যাশবোর্ড অ্যাক্সেস
  - উদ্দেশ্য: এডমিন ইউজার সফলভাবে এডমিন প্যানেলে প্রবেশ করতে পারছেন কিনা পরীক্ষা করা।
  - পদক্ষেপ: 
    1. /login পেজে গিয়ে Admin Credentials দিয়ে লগইন করুন।
    2. Admin Dashboard স্ক্রিনে রিডাইরেক্ট হওয়া সুনিশ্চিত করুন।
  - প্রত্যাশিত ফলাফল: Admin token জেনারেট হবে এবং Admin Panel লোড হবে।

Test Case 1.2: ডাটাবেস কনফিগ টেবিল টেস্ট (Config Table Marks & Time Control)
  - উদ্দেশ্য: Mock Test এবং Model Paper এর সময় (Time Allowed) ও মোট নম্বর (Total Marks) ডাটাবেস Config টেবিল থেকে কনফিগার করা।
  - পদক্ষেপ:
    1. Admin Panel -> Exam Settings টেবিল খুলুন।
    2. ICSE Class 10 Math Specimen Paper 2027 এর জন্য Time: 180 Mins, Total Marks: 80 সেট করে Save করুন।
    3. API Response `/api/v1/config/exam` কল টেস্ট করুন।
  - প্রত্যাশিত ফলাফল: ফ্রন্টএন্ড মডেল পেপারে নতুন টাইম এবং মার্কস অটোমেটিক্যালি রিফ্লেক্ট করবে।

Test Case 1.3: Razorpay পেমেন্ট গেটওয়ে কনফিগারেশন টেস্ট
  - উদ্দেশ্য: Razorpay Key ID এবং Secret Key সঠিকভাবে backend `.env` এবং কনফিগারে লোড হচ্ছে কিনা যাচাই।
  - পদক্ষেপ:
    1. Razorpay Test Mode Credentials সেট করুন।
    2. API `/api/v1/payment/create-order` টেস্ট কল করুন।
  - প্রত্যাশিত ফলাফল: Valid Order ID এবং Amount (INR 499/999) রিটার্ন করবে।

                       Phase 2: Parent Registration & Child Profile Onboarding
----------------------------------------------------------------------------------------------------
Test Case 2.1: স্ট্যান্ডার্ড ও গুগল রেজিস্টারেশন (Parent Registration & Google Sign-In)
  - উদ্দেশ্য: অভিভাবক সাধারণ সাইন-আপ ফর্ম বা Google Sign-In দিয়ে অ্যাকাউন্ট তৈরি করতে পারছেন।
  - পদক্ষেপ:
    1. `/login` পেজে গিয়ে 'Sign Up' বা 'Sign In' ট্যাবে ক্লিক করুন।
    2. 'Continue with Google' এ ক্লিক করে গুগল অ্যাকাউন্ট নির্বাচন করুন অথবা নাম, ইমেল ও পাসওয়ার্ড দিয়ে রেজিস্টার/লগইন করুন।
  - প্রত্যাশিত ফলাফল: অ্যাকাউন্ট সফলভাবে তৈরি/লগইন হবে এবং Parent Dashboard এ পাসওয়ার্ড ছাড়াই রিডাইরেক্ট হবে।

Test Case 2.2: সন্তান যুক্তকরণ (Add Child Profile)
  - উদ্দেশ্য: অভিভাবক ড্যাশবোর্ড থেকে সন্তান (Student) প্রোফাইল তৈরি ও লিঙ্ক করা।
  - পদক্ষেপ:
    1. Parent Dashboard -> 'Add Child' বাটনে ক্লিক করুন।
    2. সন্তানের নাম (e.g., 'Rahul Das'), স্কুল (e.g., 'St. Xavier's ICSE'), বোর্ড (ICSE) এবং ক্লাস (Class 10) লিখুন।
    3. Submit করুন।
  - প্রত্যাশিত ফলাফল: Student ID তৈরি হবে এবং Parent ড্যাশবোর্ডে Rahul Das কার্ড যুক্ত হবে।

                       Phase 3: Student Login & Default API Checks
----------------------------------------------------------------------------------------------------
Test Case 3.1: সন্তান/স্টুডেন্ট লগইন (Student Login via Credentials / Google)
  - উদ্দেশ্য: শিক্ষার্থী নিজের অ্যাকাউন্ট ব্যবহার করে সিস্টেমে প্রবেশ করতে পারছে।
  - পদক্ষেপ:
    1. স্টুডেন্ট ক্রেডেনশিয়ালস দিয়ে বা Google Sign-In দিয়ে লগইন করুন।
    2. স্টুডেন্ট ড্যাশবোর্ডে রিডাইরেক্ট হওয়া চেক করুন।
  - প্রত্যাশিত ফলাফল: Student JWT Token ব্রাউজারে সেভ হবে এবং Student Dashboard ওপেন হবে।

Test Case 3.2: ড্যাশবোর্ড ডেফোল্ট এপিআই চেক (Default APIs Verification)
  - উদ্দেশ্য: ড্যাশবোর্ড লোড হওয়ার সময় সমস্ত এপিআই যেমন সাবজেক্ট লিস্ট, উপলব্ধ মক টেস্ট, গ্যামিফিকেশন XP ইত্যাদি সঠিকভাবে কাজ করছে কিনা।
  - এপিআই চেকলিস্ট:
    ✓ GET `/api/v1/user/profile` -> Valid User Profile Payload
    ✓ GET `/api/v1/mock-tests/available` -> Subject-wise 10-mark free sprint tests
    ✓ GET `/api/v1/model-papers/catalog` -> ICSE & CBSE 2027 Specimen Model Test Papers
    ✓ GET `/api/v1/gamification/stats` -> Student XP, Badges & Streaks
  - প্রত্যাশিত ফলাফল: প্রতিটি API STATUS 200 OK রিটার্ন করবে এবং ড্যাশবোর্ডে সঠিক তথ্য দেখাবে।

----------------------------------------------------------------------------------------------------
                       Phase 4: Adaptive Test Engine & Question Arena Execution
----------------------------------------------------------------------------------------------------
Test Case 4.1: অ্যাডাপ্টিভ টেস্ট রুল টেস্ট (Adaptive Difficulty Logic)
  - উদ্দেশ্য: শিক্ষার্থীর উত্তর দেওয়া পারফরম্যান্স অনুযায়ী প্রশ্নপত্র স্বয়ংক্রিয়ভাবে সহজ/কঠিন হচ্ছে কিনা।
  - পদক্ষেপ:
    1. Free Mock Test / Adaptive Test শুরু করুন। প্রথম প্রশ্ন EASY লেভেল আসবে।
    2. পর পর ২টি প্রশ্নের সঠিক উত্তর দিন -> নোটিফিকেশন আসবে "Level Increased to MEDIUM"।
    3. পর পর ২টি প্রশ্নের আবার সঠিক উত্তর দিন -> নোটিফিকেশন আসবে "Level Escalated to HARD"।
    4. পরবর্তী ২টি প্রশ্ন ভুল/স্কিপ করুন -> নোটিফিকেশন আসবে "Difficulty Adjusted Back to MEDIUM"।
  - প্রত্যাশিত ফলাফল: টেস্ট ইঞ্জিন উত্তর অনুযায়ী লজিক্যালি লেভেল পরিবর্তন করবে এবং দুর্বল অধ্যায়ের ডাটা রেকর্ড করবে।

Test Case 4.2: ইন্টারেক্টিভ ক্যানভাস ড্রয়িং, ম্যাথ সিম্বল ও ডায়াগ্রাম অ্যাটাচমেন্ট (Interactive Canvas Drawing)
  - উদ্দেশ্য: শিক্ষার্থী কোনো টেক্সট নোটের উপর নির্ভর না করে সরাসরি ক্যানভাস পপআপে হাতে এঁকে চিত্র (Ray diagrams, geometry, circuits, graphs) সংযুক্ত করতে পারেন।
  - পদক্ষেপ:
    1. ICSE 80-Mark Subjective Question এ যান।
    2. Quick Math Symbol Bar থেকে `√`, `π`, `θ`, `Δ` সিম্বল বাটনে ক্লিক করুন -> টেক্সট এরিয়াতে সিম্বল যুক্ত হবে।
    3. 'Draw Diagram / Sketch 🎨' বাটনে ক্লিক করুন।
    4. 🎨 **Interactive Drawing Canvas Modal** ওপেন হবে:
       - পেন্সিল/পেন টুল নির্বাচন করুন
       - কালার প্যালেট (Black, Blue, Red, Emerald, Purple) থেকে রঙ বেছে নিন
       - স্ট্রোক থিকনেস (Thin, Medium, Thick) এবং রবার/ইরেজার টুল টেস্ট করুন
       - ক্যানভাসে মাউস/টাচ দিয়ে একটি ডায়াগাম/চিত্র আঁকুন
       - 'Attach Drawn Diagram to Answer 🎨' বাটনে ক্লিক করুন।
  - প্রত্যাশিত ফলাফল: শিক্ষার্থীর নিজের হাতে আঁকা ডায়াগ্রাম চিত্রটি (Image/PNG preview) উত্তরপত্রে সফলভাবে যুক্ত হবে এবং রেজাল্ট স্ক্রিন ও রিপোর্টে প্রদর্শিত হবে।

                       Phase 5: 15-Minute Remaining Alert & Unanswered Focus Test
----------------------------------------------------------------------------------------------------
Test Case 5.1: ১৫-মিনিটের পপআপ এবং 'লাস্ট ট্রাই' অটো-ফোকাস টেস্ট
  - উদ্দেশ্য: পরীক্ষা জমা দেওয়ার সময় যদি ১৫ মিনিটের বেশি সময় বাকি থাকে এবং কোনো প্রশ্ন বাদ গিয়ে থাকে, তবে সতর্কবার্তা দেখানো এবং সরাসরি প্রথম বাদ পড়া প্রশ্নে নিয়ে যাওয়া।
  - পদক্ষেপ:
    1. ৮-১০টি প্রশ্ন উত্তর দিয়ে কিছু প্রশ্ন ফাঁকা রাখুন।
    2. ঘড়িতে ১৫ মিনিটের বেশি সময় থাকাকালীন 'Submit Exam' বাটনে ক্লিক করুন।
    3. কনফার্মেশন পপআপ স্ক্রিন ওপেন হবে এবং হলুদ রঙের এলার্ট বক্সে দেখাবে: "১৫+ মিনিটেরও বেশি সময় বাকি আছে! আপনার এখনও X টি প্রশ্নের উত্তর দেওয়া বাকি।"
    4. পপআপে 'লাস্ট ট্রাই করুন (Go Back)' বাটনে ক্লিক করুন।
  - প্রত্যাশিত ফলাফল: পপআপ সঙ্গে সঙ্গে বন্ধ হয়ে যাবে এবং পেজটি অটো-স্ক্রোল করে প্রথম ফাঁকা থাকা প্রশ্নে নিয়ে যাবে এবং কার্ডটিতে গোল্ডেন রিং হাইলাইট দেখাবে।
  - পদক্ষেপ (পরবর্তী): উত্তর দেওয়ার পর আবার Submit এ ক্লিক করে 'পরীক্ষা শেষ (Finish)' এ ক্লিক করুন।
  - প্রত্যাশিত ফলাফল: পরীক্ষা সফলভাবে মূল্যায়নের জন্য জমা হবে।

                       Phase 6: AI Grading Engine, Report Card & Parent Email Verification
----------------------------------------------------------------------------------------------------
Test Case 6.1: এআই ইভালুয়েশন ইঞ্জিন টেস্ট (Objective Python & Subjective LLM Evaluation)
  - উদ্দেশ্য: সাবমিট হওয়া পরীক্ষার উত্তর সঠিকভাবে গ্রেড হওয়া।
  - ব্যাকএন্ড লজিক:
    - MCQ/Objective Question -> Python Deterministic Matching (১০০% নির্ভুল)
    - SAQ/Long Question -> Mistral AI LLM Board Rubric Analysis & Step Marks Awarding
  - প্রত্যাশিত ফলাফল: প্রতিটি প্রশ্নের জন্য Marks, Model Answer এবং Examiner Feedback জেনারেট হবে।

Test Case 6.2: রেজাল্ট স্কোরকার্ড ও পারফরম্যান্স ভিজ্যুয়ালাইজেশন
  - উদ্দেশ্য: পরীক্ষার পর সাথে সাথে প্রাপ্ত নম্বর, সঠিক/ভুল অ্যানালাইসিস স্ক্রিনে দেখানো।
  - প্রত্যাশিত ফলাফল: স্ক্রিনে মোট নম্বর, Accuracy %, গ্রেড (e.g., A+ / Excellent) এবং সেকশন ওয়াইজ ব্রেকডাউন দেখাবে।

Test Case 6.3: পিতা-মাতার ইমেলে স্বয়ংক্রিয় PDF রিপোর্ট পাঠানো (Automatic Parent Email Notification)
  - উদ্দেশ্য: পরীক্ষা সম্পন্ন হওয়ার পর রেজিস্টার্ড অভিভাবকের ইমেলে অ্যাটাচমেন্ট সহ বিস্তারিত PDF রিপোর্ট পাঠানো।
  - ব্যাকএন্ড এপিআই ও ইমেল সার্ভিস:
    - SMTP Mailer Gateway
    - PDF Report Generator Service (`PDF_Generator_Service.py`)
  - পরীক্ষার পদক্ষেপ:
    1. Parent Email ID (e.g. parent@example.com) এ চেক করুন।
    2. ইমেলের সাবজেক্ট ও বডি চেক করুন: "EduJunction Assessment Report: [Rahul Das] - ICSE Class 10 Mathematics"。
    3. ইমেলের সাথে যুক্ত PDF Attachment ফাইল খুলুন।
  - প্রত্যাশিত ফলাফল:
    ✓ PDF এ শিক্ষার্থীর নাম, সাবজেক্ট, তারিখ, মোট নম্বর, প্রাপ্ত নম্বর থাকবে।
    ✓ প্রতিটি প্রশ্নের সঠিক উত্তর, ভুল উত্তর এবং AI Examiner Feedback সুন্দর গ্রাফ ও টেবিলে থাকবে।
    ✓ অভিভাবকের ইমেলে শতভাগ সফলভাবে ডেলিভার হবে।
